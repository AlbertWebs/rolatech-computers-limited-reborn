# Deployment guide (draft)

This remains a deployment plan until a target host is selected. The current application was developed locally with PHP 8.4 and SQLite; its migrations and data import must be exercised against the chosen supported MySQL/MariaDB version. Use HTTPS, environment-specific `APP_KEY` and secrets, least-privilege database credentials, and writable `storage`/`bootstrap/cache`. Set `APP_DEBUG=false` in production. Configure the public document root to `public/`.

Before deployment: install locked Composer dependencies, build frontend assets, run reviewed migrations against a staging backup, configure mail/queue/cache, and create the first owner with `php artisan admin:create-user "Name" email@example.com --role=owner` (interactive password prompt; there is no default account). Assign later scoped roles with `php artisan admin:create-user ... --role=catalog|operations|content` and `php artisan admin:set-role email@example.com role`. Set scheduler and queue workers if enabled, establish encrypted backups and restore checks, verify health/log monitoring, crawl public routes, and validate payment providers in sandbox. Do not change production DNS or payment credentials as part of this draft.
